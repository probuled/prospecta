# Logos

Logo oficial enviada pela Lulu (PNG). O símbolo é um P preto com haste dourada inclinada e um ponto ouro no miolo; na logo completa ele é a primeira letra de "Prospecta". Os arquivos aqui são os originais com o fundo branco removido (transparência), recortados.

- `prospecta-logo.png` — logo completa, 1469×434, fundo transparente. Sobre `bg`/`surface` claros.
- `prospecta-logo-dark.png` — a mesma, com o preto trocado por `#EDEBE5` (ink do tema escuro); ouro intacto. Sobre `bg`/`surface` escuros. Variação derivada, não veio no envio original.
- `prospecta-simbolo.png` / `prospecta-simbolo-dark.png` — só o P, 802×802, quadrado e transparente. Sidebar recolhida, avatar, loading.
- `prospecta-app-icon.png` — o P a 62% num quadrado branco de cantos 22%. Favicon, PWA, ícone de app.
- `prospecta-app-icon-dark.png` — o P claro num quadrado `#282723`. Ícone para tema escuro.

Área de proteção: a altura do ponto ouro em volta. Tamanho mínimo: logo completa 20px de altura, símbolo 16px (abaixo disso use o app icon em 16/32px). Os arquivos são raster: para impressão grande ou recorte em vinil, peça o vetor (SVG/AI) a quem desenhou a logo.
