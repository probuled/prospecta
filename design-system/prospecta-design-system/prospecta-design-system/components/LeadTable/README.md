# LeadTable

Tabela de leads ordenada por oportunidade.

- `leads: {name, category, city, score, presence, rating, reviews, phone, status}[]`. Ordenação, paginação e seleção ficam com o consumidor.
- Colunas fixas: Negócio · Oportunidade · Presença · Avaliação · Contato · Status. Linha de 60px, cabeçalho em `surface-sunken`, hover `surface-hover`.
- Telefone em `data` com o botão WhatsApp (ícone verde, contorno neutro) à esquerda.
