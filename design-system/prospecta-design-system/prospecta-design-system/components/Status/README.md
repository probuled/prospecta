# Status

Etapa do lead no funil: marcador quadrado de 8px + palavra; por padrão é um gatilho de menu.

- `status`: `novo` (quadrado vazado), `contatado` (`info`), `respondeu` (`ouro`), `negociando` (`ameixa`), `fechado` (`sucesso`), `perdido` (`ink-faint`). `static` para só exibir.
- Nunca um pill colorido inteiro — só o marcador carrega cor.
