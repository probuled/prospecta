# Select

Gatilho de filtro que abre uma lista (o menu fica com o consumidor — use Radix/Headless UI por baixo).

- `value` (texto do valor atual), `label` opcional ("Status:"), `icon`, `active` (filtro diferente do padrão: borda em `ink`), `size: "sm"`.
- Sempre mostre o valor atual, não o nome do filtro: "Sem site próprio", "Qualquer temperatura".
- A contagem de resultados ("21 de 40") vai à direita da barra de filtros em `data`.
