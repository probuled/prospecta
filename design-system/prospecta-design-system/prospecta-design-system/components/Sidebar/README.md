# Sidebar

Navegação lateral fixa do app.

- `current` (id ativo), `collapsed` (mostra só o P da logo), `items` ({id, label, icon, count?}), `onNavigate`, `engineOnline`, `engineNote`, `theme`, `onThemeChange`.
- Fundo `bg` com borda direita `line`. Item ativo: `surface` com contorno `line` e ícone em `ouro-text` — sem barra lateral colorida.
- Rodapé: estado do motor (quadradinho `sucesso`/`quente`) e o seletor de tema.
