# Score

Score de oportunidade 0–100 com temperatura: medidor de 5 barras, número em mono e a palavra.

- `value`, `variant`: `"inline"` (padrão, na tabela) ou `"badge"` (fundo tingido, só em cards), `showWord`.
- Faixas: ≥ 80 `quente`, 50–79 `morno`, < 50 `frio` (exportado também como `scoreTemperature`). A palavra é obrigatória fora de tabelas densas — cor nunca é o único sinal.
